# Project Description

This project analyzes student academic data to understand what truly drives final exam performance. Using real student records, the study examines how factors such as attendance, study time, parental education, past failures, and previous grades relate to a student’s final grade (G3).

Instead of assuming that attendance or effort automatically leads to success, the analysis uses correlation and risk modeling to identify which variables actually predict poor performance. The results show that previous academic performance and past failures are far stronger predictors of final outcomes than attendance or reported study time.

By converting final grades into a risk label (pass vs fail), the project highlights how early academic setbacks create a downward spiral that later attendance and effort cannot easily reverse. This makes the dataset useful for building early-warning systems to identify at-risk students before failure becomes inevitable.

The goal of this project is not to describe students, but to expose the structural drivers of academic success and failure using data rather than assumptions.

## Key Findings

- Previous academic performance (G1 and G2) is the strongest predictor of final grades.
- Past failures have a much larger negative impact than attendance or study time.
- Absences show only a weak relationship with final grades.
- Early academic struggles create a downward spiral that later effort does not easily reverse.
